# EvoDesign

所思可见，所绘由心。生成、精修、编辑并导出属于你的图表。

[进入工作台](https://modelscope.cn/studios/GeminiLight/EvoDesign?mode=full) · [统一入口](https://evodesign.aurax.live/) · [源代码](https://github.com/GeminiLight/EvoDesign) · [论文](https://arxiv.org/abs/2604.09568)

默认体验使用 GLM-5.3-Flash，也可以在模型设置中连接自己的接口。项目和 DNA 保存在当前浏览器的本站点空间；切换到国际站不会自动同步，请保留原站点或导出可编辑文件。

This is the China mirror of the same EvoDesign browser release, with the same bounded GLM demo service. The complete research pipeline and self-hosted edition are available in the GitHub repository. No datasets, experiments, credentials or private development history are included in this deployment.
