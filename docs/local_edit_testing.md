# 局部编辑 API 测试指南

## 功能概述

新增了局部编辑 API，允许用户选中节点后通过聊天进行快速修改，无需完整重新生成图表。

## 实现的改动

### 后端
1. **新增 schemas** (`backend/app/schemas/diagram_generate.py`)
   - `DiagramLocalEditRequest`: 局部编辑请求
   - `DiagramLocalEditResponse`: 局部编辑响应

2. **新增服务** (`backend/app/services/local_edit_service.py`)
   - `LocalEditService`: 处理局部编辑的核心逻辑
   - 单次 LLM 调用，直接修改选中节点
   - 支持 excalidraw 和 tldraw 两种格式

3. **新增端点** (`backend/app/api/v1/endpoints/diagram.py`)
   - `POST /api/v1/diagram/edit-local`: 局部编辑端点
   - 速率限制: 20次/分钟（比全局生成更宽松）

### 前端
1. **新增类型** (`frontend/src/types/api.ts`)
   - `DiagramLocalEditRequest`
   - `DiagramLocalEditResponse`
   - 更新 `DiagramService` 接口

2. **新增 API 方法** (`frontend/src/services/apiDiagramService.ts`)
   - `editDiagramLocal()`: 调用局部编辑端点

3. **新增工具函数** (`frontend/src/utils/app.ts`)
   - `mergeDeltaIntoSchema()`: 将修改的节点合并到当前画布

4. **修改聊天逻辑** (`frontend/src/pages/WorkspacePage.tsx`)
   - `handleSendChatMessage()`: 有选中节点时使用局部编辑 API
   - 无选中节点时仍使用全局生成

## 测试步骤

### 1. 启动服务

**后端:**
```bash
cd backend
python -m uvicorn app.main:app --reload --port 3010
```

**前端:**
```bash
cd frontend
npm run dev
```

### 2. 基础功能测试

#### 测试 1: 局部位置修改
1. 打开 Workspace 页面
2. 生成一个包含多个节点的流程图（例如："创建一个包含5个步骤的流程图"）
3. 选中其中 2-3 个节点（点击节点，按住 Shift 多选）
4. 在右侧聊天栏输入："把这些节点向右移动 200 像素"
5. **预期结果:**
   - 响应时间 < 5 秒
   - 只有选中的节点移动
   - 其他节点保持不变
   - 画布原地更新，不创建新的历史记录
   - 聊天栏显示成功消息

#### 测试 2: 局部样式修改
1. 选中 2-3 个节点
2. 输入："把这些节点改成蓝色"
3. **预期结果:**
   - 只有选中节点变色
   - 其他节点颜色不变
   - 快速响应（< 5 秒）

#### 测试 3: 局部文本修改
1. 选中 1 个节点
2. 输入："把这个节点的文字改成'已完成'"
3. **预期结果:**
   - 只有选中节点的文本改变
   - 节点位置和样式不变

#### 测试 4: 局部大小修改
1. 选中 2 个节点
2. 输入："让这些节点变大一倍"
3. **预期结果:**
   - 选中节点尺寸增大
   - 其他节点不受影响

### 3. 边界情况测试

### 4. 性能测试

#### 测试 8: 响应时间对比
1. **局部编辑:** 选中节点 → 修改 → 记录时间
2. **全局生成:** 无选中 → 修改 → 记录时间
3. **预期结果:**
   - 局部编辑: 2-5 秒
   - 全局生成: 10-30 秒
   - 局部编辑至少快 5 倍

## 已知限制

1. **不支持添加新节点:** 局部编辑主要用于修改现有节点，添加新节点建议使用全局生成
2. **不支持删除节点:** 删除操作建议手动进行或使用全局生成
3. **无 undo/redo:** 当前版本不支持撤销局部编辑，需要手动恢复或重新生成
4. **LLM 质量依赖:** 单次 LLM 调用可能不如多阶段 workflow 稳定

## 故障排查

### 问题: 局部编辑没有生效
- 检查是否有节点被选中
- 查看浏览器控制台是否有错误
- 检查后端日志

### 问题: 响应很慢
- 检查 LLM API 是否正常
- 查看后端日志中的 LLM 调用时间
- 确认使用的是 `/edit-local` 而不是 `/generate`

### 问题: 修改了错误的节点
- 确认选中状态正确
- 检查 `selected_node_ids` 是否正确传递
- 查看后端日志中的 `selected_node_ids` 参数
