# Supported Diagram Types

22 diagram families. Each `diagram_type` is a snake_case slug used as the canonical identifier across the pipeline (router output, structure state, `chart_type` field).

| diagram_type | What it shows | Best for |
|---|---|---|
| architecture | layered components and bounded system regions | system architecture and layered design |
| class_diagram | compartmentalized class boxes with typed UML connectors | class structures and inheritance relationships |
| concept_map | concept nodes connected by labeled relationships | concept relationships and semantic links |
| data_flow_diagram | external entities and stores connected through labeled process flows | data flow and processing procedures |
| er_diagram | entity rectangles connected through relationship diamonds and cardinality labels | database entity relationships and data models |
| fishbone | a main spine with alternating cause branches converging on an effect | causal analysis and root cause decomposition |
| flowchart | sequential boxes connected by directional arrows | processes, steps, and decision logic |
| funnel | stacked stages narrowing downward | conversion and screening processes |
| gantt | a time axis with horizontal duration bars | project progress and task scheduling |
| infographic | multi-module visual storytelling with mixed text and graphic elements | comprehensive information visualization |
| matrix | a labeled grid with row/column semantics | multi-dimensional comparison |
| mindmap | a central node with radiating branches | concept relationships and knowledge structures |
| network_topology | connected devices arranged as a non-linear topology | network structures and node connections |
| orgchart | a top-down tree with clear levels | organizational structures and hierarchies |
| pyramid | stacked levels widening downward | hierarchy and priority |
| sequence_diagram | horizontal participants with vertical lifelines and ordered message arrows | system interactions and message passing |
| state_diagram | lifecycle states connected by labeled transitions | state transitions and lifecycles |
| swimlane | parallel lanes combining ownership and flow | cross-role processes and responsibility division |
| swot | four equal strategic quadrants in a 2x2 matrix | strengths, weaknesses, opportunities, and threats |
| timeline | a chronological axis with ordered milestones and event cards | historical events and development history |
| tree | a root with branching descendants | hierarchical structures and classification relationships |
| venn | overlapping semi-transparent sets with no edges | set relationships and intersection/union |
