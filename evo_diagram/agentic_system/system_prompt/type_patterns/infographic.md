## Infographic

### Common
- Best for comprehensive information visualization.
- Identity signal: multi-module visual storytelling with mixed text and graphic elements.

#### Visual Pattern
```
┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│   Title     │ │   Stat 1    │ │   Stat 2    │
│   Block     │ │   87%       │ │   1.2M      │
└─────────────┘ └─────────────┘ └─────────────┘
┌─────────────────────────────────────────────┐
│            Process / Timeline                 │
│   Step 1 ──► Step 2 ──► Step 3 ──► Step 4   │
└─────────────────────────────────────────────┘
┌─────────────┐ ┌─────────────┐
│  Chart A    │ │  Chart B    │
│  [bar]      │ │  [pie]      │
└─────────────┘ └─────────────┘
```

### Structure
- Use modular information blocks rather than one single graph grammar.
- Combine text, numbers, icons, and chart-like units into a unified narrative.
- Modules can be semi-independent, but all should support the same communication goal.
- [Budget] 4-12 showcase tiles; optional 0-3 groups for sections; [] edges unless explicit arrow metaphor in source
- [Edge Rules] Expected count: 0. Tiles are independent. Only emit edges if explicit arrow metaphor in source.

### Styling
- Use frames and rectangles to create independent information modules.
- Establish visual hierarchy through size, color, and positioning.
- Use multiple colors, charts, icons, and numerical callouts while keeping modules visually coherent.
- Integrate text and graphics closely to improve communication efficiency.

### Layout
- Use a modular, section-based layout.
- Allocate distinct canvas regions to different information modules.
- Preserve a clear scan order across sections instead of forcing one rigid diagram family.
- [Geometry] Showcase tiles arranged freely. 4-12 tiles. Each tile is self-contained with icon/shape + text. Optional section groups. NO arrows unless explicit metaphor.
