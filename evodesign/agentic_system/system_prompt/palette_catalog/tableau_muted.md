## tableau_muted

**display_name:** Tableau Muted

**digest:** BI dashboards, KPI rollups, multi-series Gantt, executive analytics.

**mood:** Business-analytics polish — muted hues that stay distinct at thumbnail size without fatigue.

**use_when:** BI dashboards, KPI rollups, multi-series Gantt charts, executive analytics — anywhere muted-yet-distinct categorical hues must read at thumbnail size without fatigue.

**avoid_when:** Kid-facing content (too subdued), creative brainstorm (too professional), warm-mood marketing (too cool), pure technical engineering (lacks gravitas). When the audience expects warmth, urgency, or playfulness, pick differently.

**reference_anchors:** Tableau dashboard defaults, Power BI gallery, Looker explorer themes, FT and Economist data graphics.

**balance_guidance:** Blue is the lead `primary metric` voice (~30-40%). Teal for supporting metrics. Orange and red for highlights and warnings (<=15% each — Tableau-style `exceptions matter`). Purple for special-case categories. The whole diagram should read at glance even shrunken — no hue should overwhelm.

**common_mistakes:** Oversaturating orange (it's the warning accent, not a narrator). Using red for routine differentiation (it should mean `this is the bad number`). Letting purple expand beyond special cases (it has a `different category` meaning here).

**canvas:** `#FAFAFA`
**border_default:** `#252525`
**accent_edge:** `#1F4E79`

### Fill Families

| name | fill | stroke | voice |
|------|------|--------|-------|

| teal | `#CCFBF1` | `#115E59` | Supporting metrics — secondary numbers, related dimensions, the `compare to` lane. |
| orange | `#FED7AA` | `#9A3412` | Warning or `this changed` callouts — exceptions worth flagging. |
| red | `#FECACA` | `#B91C1C` | True bad numbers — over-budget, missed-target, exception nodes (<=10%). |
| purple | `#F3E8FF` | `#6B21A8` | Special-case categories — different-from-the-norm dimensions, `the outlier worth examining`. |
