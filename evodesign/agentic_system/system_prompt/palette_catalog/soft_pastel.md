## soft_pastel

**display_name:** Soft Pastel Refined

**digest:** Tier C / 柔和参考 — brainstorming, workshops, journal-style maps; pretty but low hierarchy.

**mood:** A bullet-journal mindmap on cream paper — pink, sky, lilac, mint washes that don't compete for attention.

**use_when:** Design-thinking workshops, brainstorming mind maps, creative-process diagrams, journal-style note layouts — anywhere `pleasant, low-stakes, exploratory` should read.

**avoid_when:** Enterprise (reads as unprofessional), healthcare-clinical (reads as casual), technical engineering (reads as decorative), high-stakes decision making. The palette has no strong focal accent by design, so it cannot carry urgency.

**reference_anchors:** Notion templates, Miro workshop boards, Pinterest mood boards, bullet-journal Instagrams, Figjam brainstorm canvases.

**balance_guidance:** Multiple families can mingle freely — pastels are designed to coexist without competing. Pink, sky, lilac, mint, peach can each carry ~20%. Don't impose a hierarchy unless one node truly is `the main idea`. The diagram should feel like an inviting page where every idea has room.

**common_mistakes:** Trying to make pastels carry hierarchy by saturating one family (defeats the palette's gentle character). Using this for content where one node MUST stand out — pick a different palette. Forcing `matching` rules — let casual variation breathe.
