## Swot

### Common
- Best for strengths, weaknesses, opportunities, and threats.
- Identity signal: four equal strategic quadrants in a 2x2 matrix.

#### Visual Pattern
```
┌───────────────┬───────────────┐
│   Strengths   │  Weaknesses   │
│   (top-left)  │  (top-right)  │
├───────────────┼───────────────┤
│ Opportunities │    Threats    │
│  (bottom-left)│ (bottom-right)│
└───────────────┴───────────────┘
```

### Structure
- Use exactly four semantic groups: Strengths, Weaknesses, Opportunities, and Threats.
- Quadrant grouping is exhaustive: content belongs inside one of the four labeled regions.
- The meaning comes from quadrant ownership rather than from dense edge structure.
- [Budget] 1 per cell (≤ rows × cols); 0 groups (grid is the organizer); [] edges
- [Edge Rules] Expected count: 0. Cells communicate by position.

### Styling
- Use rectangles to create four quadrants.
- Use distinct colors for Strengths, Weaknesses, Opportunities, and Threats.
- Render key points within each quadrant rather than over-emphasizing connectors.

### Layout
- Primary family: Grid / Matrix.
- Use a 2x2 matrix layout with quadrants of equal size.
- Preserve explicit gutters and clean alignment between quadrants.
- Avoid unequal quadrants or unlabeled cells.
- [Geometry] 2×2 grid layout. Four quadrants: Strengths (top-left), Weaknesses (top-right), Opportunities (bottom-left), Threats (bottom-right). Uniform cell sizes. NO connecting arrows.
