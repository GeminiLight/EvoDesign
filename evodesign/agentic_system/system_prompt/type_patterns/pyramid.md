## Pyramid

### Common
- Best for hierarchy and priority.
- Identity signal: stacked levels widening downward.

#### Visual Pattern
```
         ┌─────┐
         │Goal │
       ┌─┴─────┴─┐
       │Strategy │
     ┌─┴─────────┴─┐
     │   Tactics   │
   ┌─┴─────────────┴─┐
   │    Operations   │
   └─────────────────┘
```

### Structure
- Use stacked levels to represent hierarchy or priority.
- Each content item should map clearly to a specific level.
- Meaning is reinforced by the top-to-bottom change in breadth.
- [Budget] 1 per level (3-6); 0 groups; [] edges
- [Edge Rules] Expected count: 0. Levels communicate by geometry.

### Styling
- Use rectangular or banded layers that together form a pyramid silhouette.
- Use color gradients to reflect hierarchical relationships.
- Keep tier boundaries visually clear.

### Layout
- Center the composition vertically.
- Increase level width from top to bottom to form the pyramid shape.
- Preserve symmetry around the center axis when possible.
- [Geometry] Stacked levels, widest at bottom, narrowest at top. 3-6 levels. Each level is a horizontal band. Labels centered in each band. NO arrows between levels.
