# WP28 浏览器渲染对照

前端 `pipelineRenderer.ts` 实现 `PngRenderer`，使用 Excalidraw 0.18.0 导出 PNG。Node 平台保留 3001 服务页与 Playwright 渲染；两边复用背景、字体、padding、scale、视口及边界处理约定。

`npm run parity:render` 对 112 组阶段最终 manifest 分别执行 product 与 analysis，合计 224 组，每组比较原图和 smart crop 后的图片。判定要求尺寸相等，任一通道差值大于 16 的像素占比不超过 0.5%；裁剪说明和裁剪框也必须相同。最终结果见 `../PHASE3_REPORT.md` 和 `reports/wp28/summary.json`。

2026-11-06 最终运行：224/224 通过，原图字节与像素完全一致 224/224，最大通道差 0，smart crop 一致 224/224，无警告。

脚本为 `tools/wp28/compare-renderers.ts`，浏览器测试入口为 `frontend/test-pages/pipeline-renderer.html`。默认使用 3001 渲染服务；Vite 测试页使用 5179。首次 Vite 启动需要满足 Node >=22.12。
